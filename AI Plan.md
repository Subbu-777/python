# AI Learning Plan - 6 Months Detailed

## Month 1 - Python & Math Refresh
**Goal:** Master Python basics and math foundations for AI.

**Weekly Breakdown:**

**Week 1: Python Basics**
- Topics: Variables, data types, loops, conditions
- Exercises:
  1. Write a program to check if a number is prime.
  2. Create a simple calculator using functions.
- Resources: 
  - [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/)
  - [HackerRank Python Basics](https://www.hackerrank.com/domains/python)

**Week 2: Functions & OOP**
- Topics: Functions, classes, objects
- Exercises:
  1. Build a `BankAccount` class with deposit/withdraw methods.
  2. Implement inheritance: `SavingsAccount` and `CheckingAccount`.

**Week 3: Numpy & Pandas**
- Topics: Arrays, DataFrames, basic data operations
- Exercises:
  1. Load a CSV file and compute mean, median, and mode.
  2. Perform filtering & grouping on a dataset (e.g., Titanic dataset).
- Resources: [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/)

**Week 4: Math Foundations**
- Topics: Linear algebra (vectors, matrices), probability, statistics
- Exercises:
  1. Compute the dot product and cross product of vectors.
  2. Calculate mean, variance, and standard deviation for a dataset.
- Resources: [Khan Academy - Linear Algebra & Probability](https://www.khanacademy.org/math)

**Mini-Project:** Analyze a dataset (Netflix movies or Titanic) using Pandas & Matplotlib, visualize insights.

## Month 2 - Machine Learning Fundamentals
**Goal:** Understand ML algorithms and evaluation metrics.

**Week 1: Supervised Learning Basics**
- Topics: Linear & Logistic Regression
- Exercises:
  1. Predict house prices using Linear Regression.
  2. Predict if a student passes/fails using Logistic Regression.
- Practice Questions:
  - What is overfitting and how to prevent it?
  - Difference between classification and regression.
